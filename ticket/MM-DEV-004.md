# Korean Transcriber — 개발 티켓 MM-DEV-004

**단계:** M1

### MM-DEV-004 [Algorithm] 녹음 간 초기 오프셋 추정 및 신뢰도 산출

- **우선순위:** P0
- **선행 작업:** MM-DEV-002
- **검증 시나리오:** MM-01, MM-07
- **목적:** 공통 발화를 기준으로 파일 사이 녹음 시작 시차를 추정한다.

**구현 작업**

- [ ] 기준 파일 기준 16 kHz 분석 신호에서 여러 유효 음성 시간창을 선택한다.
- [ ] 정규화 상호상관을 기본으로 하고 필요하면 GCC-PHAT를 비교한다.
- [ ] 복수 피크·시간창별 편차를 사용하여 offset_ms 및 confidence를 계산한다.
- [ ] 공유 이벤트가 적거나 상관관계가 낮으면 자동 정렬 실패로 판정한다.
- [ ] 파일 생성 시각만으로 오프셋을 결정하지 않는다.

**주요 대상 파일**

- `engine/multimic/align.py (신규)`
- `engine/multimic/pipeline.py (신규)`

**완료 조건 (Acceptance Criteria)**

- [ ] 충분한 공통 발화가 있는 ±0.5초 합성 시차를 추정하며 오차 20ms 이하는 초기 목표로 측정한다.
- [ ] 무관한 녹음은 정상 정렬로 반환하지 않는다.
- [ ] 오프셋·신뢰도·실패 이유를 파일별로 반환한다.

**비고:** 20ms는 실측 보증이 아닌 제안 수용 목표다.
