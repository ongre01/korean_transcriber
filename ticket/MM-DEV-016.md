# Korean Transcriber — 개발 티켓 MM-DEV-016

**단계:** M4

### MM-DEV-016 [Test] 다중 마이크 합성 테스트 및 회귀 검증 자동화

- **우선순위:** P0
- **선행 작업:** MM-DEV-004 ~ MM-DEV-015의 구현된 기능 순차 검증
- **검증 시나리오:** MM-01 ~ MM-09
- **목적:** 사양서의 MM-01~MM-09를 반복 실행 가능하게 만들어 정확성과 안전성을 검증한다.

**구현 작업**

- [ ] 인위적 ±0.5초 시차·30분 드리프트·국소 잡음·클리핑·단일 마이크 발화·부분 녹음·무관한 파일 데이터를 생성한다.
- [ ] 오프셋 목표(20ms) 및 드리프트 결과는 환경/데이터 조건과 함께 측정한다.
- [ ] 채널 선택 히스테리시스, 출력 시간축 보존, 누락 구간 처리, JSON 계약을 테스트한다.
- [ ] 단일 파일 모드 회귀 및 중단/실패·파일 보존 테스트를 추가한다.
- [ ] 테스트 결과를 재현 가능한 명령/로그로 남긴다.

**주요 대상 파일**

- `engine/tests/test_multimic_*.py (신규 제안)`
- `engine/tests/test_backend_protocol_warning.py 등 기존 테스트 (필요 시 확장)`
- `GUI 테스트 환경 (신규/확장)`

**완료 조건 (Acceptance Criteria)**

- [ ] MM-01~MM-09에 해당하는 자동 또는 절차 테스트가 문서화된다.
- [ ] 비정상 입력·취소가 정상 완료로 표시되지 않는다.
- [ ] 통합 테스트가 기존 단일 입력 계약을 훼손하지 않는다.

**비고:** 이 티켓은 M1 초기부터 테스트 픽스처를 병행 작성한다.
