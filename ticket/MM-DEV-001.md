# Korean Transcriber — 개발 티켓 MM-DEV-001

**단계:** M1

### MM-DEV-001 [GUI] 다중 마이크 파일 입력 화면 및 모델 구현

- **우선순위:** P0
- **선행 작업:** 없음
- **검증 시나리오:** MM-08
- **목적:** 기존 단일 파일/실시간 녹음 모드를 유지하면서 오프라인 복수 파일 입력을 제공한다.

**구현 작업**

- [ ] 기본 입력 상태는 기존 단일 파일로 유지하고 `다중 마이크 파일` 모드를 추가한다.
- [ ] `QFileDialog::getOpenFileNames()`로 2개 이상 파일을 선택하고, 파일 추가·제거·사용 여부·별칭 편집·기준 채널 선택 기능을 제공한다.
- [ ] 파일 테이블에 파일/길이/마이크 별칭/정렬 오프셋/신뢰도/상태를 표시할 모델을 구현한다.
- [ ] 기존 단일 파일 및 실시간 녹음 메뉴가 동작하도록 상태 전환을 처리한다.

**주요 대상 파일**

- `gui/mainwindow.*`
- `gui/input/MultiAudioInputDialog.* (신규)`
- `gui/input/MultiAudioInputModel.* (신규)`
- `gui/AudioTranscriber.pro`

**완료 조건 (Acceptance Criteria)**

- [ ] 다중 파일 2개 이상 등록과 제거가 가능하다.
- [ ] 사용자가 마이크 별칭과 기준 파일을 지정할 수 있다.
- [ ] 기본 단일 파일 입력과 실시간 녹음 기능이 유지된다.
- [ ] UI 메인 스레드는 장시간 블로킹되지 않는다.
