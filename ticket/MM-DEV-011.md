# Korean Transcriber — 개발 티켓 MM-DEV-011

**단계:** M2

### MM-DEV-011 [GUI] 음질 분석 결과·수동 채널 선택·통합 입력 검토

- **우선순위:** P1
- **선행 작업:** MM-DEV-006, MM-DEV-009, MM-DEV-010
- **검증 시나리오:** MM-03, MM-09
- **목적:** 사용자가 채널 선택 근거를 확인하고 필요하면 선택 결과를 수정한다.

**구현 작업**

- [ ] `음질 분석` 비동기 실행 기능과 구간별 파일/점수/사유 테이블을 추가한다.
- [ ] 초판은 구간 테이블 중심으로 제공하고 파형·고급 타임라인은 후속으로 분리한다.
- [ ] 사용자 구간별 강제 채널 선택(override)을 반영하고 최종 선택 결과를 확인할 수 있게 한다.
- [ ] 기존 앱에 오디오 재생 기능이 없으면 `통합 음성 미리 듣기`는 별도 후속/조건부 범위로 표시한다.

**주요 대상 파일**

- `gui/input/MultiAudioInputDialog.*`
- `gui/input/MultiAudioInputModel.*`
- `gui/mainwindow.*`

**완료 조건 (Acceptance Criteria)**

- [ ] 사용자가 자동 선택 구간과 수동 조정 결과를 구분할 수 있다.
- [ ] 수동 조정 후 결과 합성/전사에 변경 내용이 적용된다.
- [ ] 음질 분석 중 UI가 멈추지 않는다.

**비고:** 재생 기능은 사양서상 지원 시에만 제공하는 조건부 항목이다.
