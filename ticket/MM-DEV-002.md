# Korean Transcriber — 개발 티켓 MM-DEV-002

**단계:** M1

### MM-DEV-002 [Backend] 다중 오디오 메타데이터 검증·디코드·모노 변환

- **우선순위:** P0
- **선행 작업:** 없음
- **검증 시나리오:** MM-06
- **목적:** 상이한 포맷·샘플레이트·채널 수의 입력을 안전하게 공통 분석 표현으로 변환한다.

**구현 작업**

- [ ] WAV/MP3/M4A/AAC/FLAC/OGG/MP4, 파일 존재/디코드 가능 여부, 길이, 샘플레이트, 채널 수를 검사한다.
- [ ] 2개 미만 파일은 거부하고 초기 UI 권장 상한 8개를 안내한다(백엔드의 기술적 제한으로 고정하지 않음).
- [ ] 파일별 스테레오·멀티채널 입력은 V1에서 모노 신호 하나로 변환하고 변환 방법을 메타데이터로 남긴다.
- [ ] 임시 분석용 공통 16 kHz 신호를 제공하고 원본 파일은 수정하지 않는다.
- [ ] 시작/종료 구간을 유효 마스크로 표현해 녹음 누락 구간을 단순 무음으로 취급하지 않는다.

**주요 대상 파일**

- `engine/audio_metadata.py (확장 또는 재사용)`
- `engine/multimic/pipeline.py (신규)`

**완료 조건 (Acceptance Criteria)**

- [ ] 서로 다른 샘플레이트와 스테레오/모노 파일을 함께 처리할 수 있다.
- [ ] 파일 없음·손상·디코드 불가 시 파일별 원인을 반환한다.
- [ ] 원본 파일 해시/크기가 처리 전후 동일하다.
- [ ] 미녹음 구간이 품질 점수 대상에서 제외된다.
