# Korean Transcriber — 개발 티켓 MM-DEV-017

**단계:** M4

### MM-DEV-017 [Evaluation] 실제 한국어 회의 녹음 CER/WER 비교 평가

- **우선순위:** P1
- **선행 작업:** MM-DEV-015, MM-DEV-016
- **검증 시나리오:** MM-10
- **목적:** 다중 채널 선별이 단일 파일 전사보다 실사용에서 유리한지 정량 검증한다.

**구현 작업**

- [ ] 동일 회의를 여러 장치로 녹음한 허가된 평가 데이터를 준비한다.
- [ ] 단일 최적 파일 vs 다중 통합 입력 조건으로 동일 Whisper/화자 분리 설정을 사용한다.
- [ ] CER/WER, 누락 발화 수, 화자 배정 오류, 처리 시간, 전환 수를 비교한다.
- [ ] 반향/오버랩/서로 다른 거리의 발화 등 실패 구간을 진단한다.
- [ ] V1 알고리즘의 가중치 보정과 V2 필요 항목을 기록한다.

**주요 대상 파일**

- `평가 데이터 및 실행 스크립트 (신규 제안)`
- `engine/multimic/quality.py (설정 가중치 조정 시)`
- `성능 평가 문서 (신규)`

**완료 조건 (Acceptance Criteria)**

- [ ] 측정 데이터/설정/조건/결과가 재현 가능하다.
- [ ] 성능 개선이 없거나 악화되는 사례까지 포함해 결과를 보고한다.
- [ ] 실측하지 않은 논문 수치를 V1의 개선량으로 주장하지 않는다.
