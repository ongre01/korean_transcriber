# Korean Transcriber — 개발 티켓 MM-DEV-007

**단계:** M2

### MM-DEV-007 [VAD] 마이크별 음성 검출 결과를 결합한 발화 구간 생성

- **우선순위:** P0
- **선행 작업:** MM-DEV-002, MM-DEV-005
- **검증 시나리오:** MM-05, MM-06
- **목적:** 어느 한 마이크에만 수집된 발화도 후보 구간에서 누락되지 않게 한다.

**구현 작업**

- [ ] `engine/vad.py`의 기존 VAD를 재사용/확장한다.
- [ ] 마이크별 발화 구간을 기준 시간축으로 사상하고 유효 구간을 고려해 union 후보를 만든다.
- [ ] 초기 분석 창 3초/이동 1초(설정 가능) 기준으로 특징 계산 단위를 생성한다.
- [ ] 잡음만 큰 입력을 발화로 단정하지 않는 판정·진단 정보를 남긴다.

**주요 대상 파일**

- `engine/vad.py`
- `engine/multimic/quality.py (신규)`

**완료 조건 (Acceptance Criteria)**

- [ ] 한 파일에만 존재하는 실제 발화가 후보 구간에 포함된다.
- [ ] 입력이 없는 시간창을 무음 발화로 오판하지 않는다.
- [ ] 발화 경계/구간 정보가 후속 선택 단계에 제공된다.
