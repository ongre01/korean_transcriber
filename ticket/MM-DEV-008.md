# Korean Transcriber — 개발 티켓 MM-DEV-008

**단계:** M2

### MM-DEV-008 [Algorithm] 채널별 SNR·클리핑·유효성 기반 음질 점수

- **우선순위:** P0
- **선행 작업:** MM-DEV-007
- **검증 시나리오:** MM-03, MM-04
- **목적:** 단순 음량이 아닌 전사 적합도에 근거한 채널별 품질 점수를 산출한다.

**구현 작업**

- [ ] 음성 존재, 추정 SNR, 클리핑, 유효 구간을 분석한다.
- [ ] 특징 정규화·가중치를 설정으로 격리하며 점수 근거를 기록한다.
- [ ] 단순 최대 RMS 선택은 금지한다.
- [ ] 클리핑/녹음 끊김에 명시적 패널티를 둔다.
- [ ] 명료도 대리 지표는 계산량·신뢰성 검증 뒤 선택적으로 적용한다.

**주요 대상 파일**

- `engine/multimic/quality.py (신규)`

**완료 조건 (Acceptance Criteria)**

- [ ] 특정 파일에만 추가된 잡음 구간에서 정상 파일이 우선 평가된다.
- [ ] 클리핑이 추가된 구간의 해당 채널 점수가 감소한다.
- [ ] 유효성 없는 입력에는 점수를 부여하지 않는다.
