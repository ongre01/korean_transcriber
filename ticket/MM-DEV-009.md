# Korean Transcriber — 개발 티켓 MM-DEV-009

**단계:** M2

### MM-DEV-009 [Algorithm] 구간별 최적 채널 선택 및 전환 안정화

- **우선순위:** P0
- **선행 작업:** MM-DEV-008
- **검증 시나리오:** MM-03, MM-05
- **목적:** 잡음·클리핑을 피하면서 전환 횟수와 발화 손실을 억제한다.

**구현 작업**

- [ ] 구간 점수로 채널을 선정하되 미세한 차이는 이전 채널을 유지하는 히스테리시스를 적용한다.
- [ ] 초기 최소 유지 구간을 2~3초의 조정 가능한 값으로 두고 다른 파일에만 발화가 존재하는 경우 예외 전환한다.
- [ ] 전환점은 가능한 무음/발화 경계로 이동한다.
- [ ] 사용자가 지정한 구간 수동 선택 결과를 반영할 확장 지점을 만든다.
- [ ] 모든 채널 불량 시 구간을 삭제하지 않고 가장 유효한 원본과 경고를 남긴다.

**주요 대상 파일**

- `engine/multimic/select.py (신규)`

**완료 조건 (Acceptance Criteria)**

- [ ] 최종 구간이 기준 타임라인을 빠짐없이 덮는다.
- [ ] 채널 전환이 불필요하게 반복되지 않는다.
- [ ] 한 마이크에만 있는 발화의 누락을 억제하는 전환 예외가 동작한다.
